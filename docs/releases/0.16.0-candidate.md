按中英文升级手册执行备份、只读预览、人工审阅修订值、显式应用和分阶段核对。受影响记录保持原Ref；维护围栏绑定原始日志及完整恢复快照摘要，跨重启保留。中断后使用同一日志续接，不自动重新预览并套用新修订值。先排空在途操作，停止旧合计/报警任务，维护完成后只保留一套新任务。

Follow the bilingual upgrade guide: recoverable FIN backup, read-only preview, review the exact revision, explicit apply and per-store checks. Affected records retain IDs. Persistent maintenance ownership binds the original journal and recovery snapshot digest across restart. Resume that journal after interruption; do not automatically generate and apply a new revision. Drain in-flight operations, stop old jobs, and retain one active job set after acceptance.

Migration only rewrites owned tags, supported internal expressions and owned references. Review custom external Axon callers, bookmarks, integrations and user-authored expressions separately; do not globally replace arbitrary customer strings. The new Pod reads only each explicitly configured primary point's native history. It does not relocate or create a replacement time-series store.
